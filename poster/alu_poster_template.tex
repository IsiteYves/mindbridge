% --- SECTION 1: MAUNICE AKALIZA ---
\block{1. Problem, Context, and Users}{
\begin{itemize}
  \item \textbf{Context \& Stress:} ALU students face overlapping deadlines; 83\% surveyed reported moderate to very high academic stress.
  \item \textbf{Current Gap:} Canvas lists due dates without splitting work into tasks.
  \item \textbf{Solution:} MindBridge helps students organize tasks and plan workloads.
\end{itemize}
}


% --- SECTION 2: MAUNICE AKALIZA ---
\block{2. Objectives and Scope}{
\begin{itemize}
  \item \textbf{Objective:} Build a web app that simplifies workload planning and reduces last-minute pressure.
  \item \textbf{Scope:} Imports Canvas tasks, tracks deadlines, and splits rubrics into dated milestones for ALU students.
\end{itemize}
}

% --- SECTION 4: JOEL & ESTHER ---
\block{4. Constraints and Design Decisions}{
\begin{itemize}
  \item \textbf{Security:} Fernet-encrypted Canvas tokens, PyJWT sessions, and manual import fallback.
  \item \textbf{Stack:} React + TypeScript, Flask, and PostgreSQL for fast build and clear data tracking.
  \item \textbf{Trade-Off:} Prioritized core planning and burnout support over clinical care or external calendar sync.
\end{itemize}
}

% --- SECTION 6: YVES ISITE ---
\block{6. Methodology and Build Process}{
We built MindBridge over a 4-week sprint (Oct 28 -- Nov 23, 2026) in clear steps:
\begin{itemize}
  \item \textbf{Plan:} Reviewed ALU student workload needs and designed the React, Flask, and PostgreSQL architecture.
  \item \textbf{Build:} Implemented Canvas import, rubric-to-milestone splitting, check-ins, focus timer, and heatmap.
  \item \textbf{Test \& Review:} Ran automated backend tests, manual workflow checks, and a 10-student pilot review.
\end{itemize}
}
